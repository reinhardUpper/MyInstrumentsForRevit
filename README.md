# MyInstrumentsForRevit

Набор личных C# инструментов для Autodesk Revit.

## Структура

- `src/MyInstrumentsForRevit/App.cs` - точка входа add-in и регистрация ленты.
- `src/MyInstrumentsForRevit/Ribbon` - сборка вкладки, панели и кнопок.
- `src/MyInstrumentsForRevit/Commands` - отдельные команды Revit.
- `src/ContextFilter.Core` - модели и контракты Context Filter.
- `src/ContextFilter.UI` - WPF-интерфейс Context Filter и Snake.
- `src/ContextFilter.Plugin` - Revit add-in для Context Filter.
- `deploy/Revit2021` - пример `.addin` манифеста для Revit 2021.
- `deploy/Revit2022` - пример `.addin` манифеста для Revit 2022.
- `scripts` - вспомогательные скрипты установки.

## Первый набор инструментов

На вкладке `Мои инструменты` создается панель `Настройка графики` с выпадающей кнопкой `Настройка графики`.

Также перенесен старый набор `Context Filter`: он создает панель `Фильтр и игры` на той же вкладке `Мои инструменты`.

На вкладке `Мои инструменты` создается отдельная панель `Работа с видами`.

Внутри сейчас есть:

- `Копия легенд/спец.` - дублирует выбранные на листе легенды и спецификации и размещает копии со смещением 30 мм вправо.
- `Копия вида` - дублирует размещенный план этажа, план несущих конструкций или вид-узел с детализацией и размещает копию на текущем листе в исходных координатах; окно выбора поддерживает поиск по имени вида и листу.

На вкладке `Мои инструменты` также создается панель `Работа с фильтрами`.

Внутри сейчас есть:

- `Обновить фильтры` - собирает существующие `ParameterFilterElement` из документа и обновляет внутренний кэш.
- `Добавить на вид` - открывает WPF-поиск по кэшу фильтров, добавляет выбранный фильтр на активный вид и переключает его видимость кнопками `Скрыть` и `Показать`.

Внутри сейчас есть:

- `Штриховка категорий` - переключает настройки для стен, перекрытий, несущего каркаса и несущих колонн:
  - штриховка поверхностей и сечений выключена;
  - при повторном запуске возвращает сохраненные настройки активного вида.
- `Вид армирования` - применяет настройки вида армирования:
  - основные конструктивные категории: линии 2, штриховка выключена;
  - категория арматуры показана.
- `Вид опалубки` - применяет настройки вида опалубки:
  - основные конструктивные категории: линии 4, штриховка выключена;
  - категория арматуры скрыта.
- `Настроить 3D вид` - применяет стандартную преднастройку к активному 3D виду:
  - графика: тонированный режим;
  - скрывает области видимости;
  - скрывает уровни;
  - скрывает оси.
- `Revit связи` - скрывает видимые Revit-связи на активном виде, сохраняет список и при повторном запуске возвращает их обратно.

## Сборка

По умолчанию проект собирается с API Revit 2021:

```powershell
dotnet build
```

Для Revit 2022, если он установлен локально:

```powershell
dotnet build -p:RevitVersion=2022
```

Также можно явно передать путь к установленному Revit:

```powershell
dotnet build -p:RevitInstallDir="C:\Program Files\Autodesk\Revit 2022"
```

## Установка

1. Соберите проект.
2. Установите актуальный общий манифест и DLL через скрипт:

```powershell
.\scripts\Install-RevitAddin.ps1 -RevitVersion 2021 -Configuration Debug
```

Для Revit 2022:

```powershell
.\scripts\Install-RevitAddin.ps1 -RevitVersion 2022 -Configuration Debug
```

Скрипт копирует сборку в `%AppData%/Autodesk/Revit/Addins/<версия>/MyInstrumentsForRevit`, ставит единый `MyInstrumentsForRevit.addin` и удаляет старый отдельный `ContextFilter.addin`.
